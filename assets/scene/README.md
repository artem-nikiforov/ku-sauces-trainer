# Сюда кладутся сгенерированные иллюстрации

## Что читать

| Файл | Для кого |
|---|---|
| [`prompts.json`](prompts.json) | **задание агенту-художнику.** 23 кадра: id, файл, размер, ракурс, готовый промт и negative prompt |
| [`PROMPTS.md`](PROMPTS.md) | то же самое для человека |

Оба файла **сгенерированы** скриптом `../../tools/build_prompts.py` из
`burger_king_style_2d.ru.json` (визуальная библия бренда, стиль
«Детализированная 2D-иллюстрация»). Базовый стиль, префиксы униформы,
палитра, свет и негативный промт взяты из библии **дословно** — чтобы
формулировки не расходились с ней.

**Править надо скрипт, а не эти два файла.** После правки:

```bash
python tools/build_prompts.py
```

## Пакет на шаге 4 — три варианта

Внутри пакета должна быть видна закуска, которую Гость выбрал на шаге 1,
поэтому пакетов три: `bag-fries`, `bag-nuggets`, `bag-wings`. Это одна
серия — совпадает всё, кроме закуски. Эталон кадра — `bag-fries.webp`
(скопирован из прежнего `bag.webp`, там была фри). Пока варианта нет,
курс рисует векторный пакет с правильной закуской.

Прежний `bag.webp` курсом больше не используется.

## Как включить готовую картинку в курс

1. Положить файл сюда: `assets/scene/<id>.webp` (id — из `prompts.json`).
2. В `js/scenes.js` в объекте `PHOTOS` переключить этот ключ в `true`.

Исключение — обложка курса: файл `hero.webp` кладётся в `assets/`, а не сюда.
Дизайн-система подхватит его сама, флаг не нужен.

Векторные заглушки в `js/scenes.js` **не удалять** даже после замены: курс
обязан открываться и без картинок — в LMS они могут не отдаться.

## Главное в приёмке

Полный список правил — в `prompts.json` → `acceptance_rules`. Два, на которых
чаще всего ломается серия:

1. **Гость во всех десяти кадрах — один человек.** `guest-1…5` и пять эмоций:
   та же причёска, та же одежда, тот же оттенок кожи. Иначе на экранах итогов
   будет десять разных людей.
2. **Униформа ЧБР — только с крупной цветной кокеткой** (зелёное плечо, ниже
   красная, тёмно-коричневая и узкая карамельно-оранжевая полосы) либо
   оранжевый верх с коричневым низом. Однотонное чёрное поло библия запрещает
   прямо, оно стоит в негативном промте.

И ещё: **логотип Burger King не рисовать.** В сценах он подставляется поверх
настоящим вектором `assets/bk_logo_vector.svg`. В промтах на его месте
заказана чистая плоская зона.
