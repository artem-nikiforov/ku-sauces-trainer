После того как файл лёг сюда, включить его в `js/scenes.js` → объект `PHOTOS`.

Дизайн-система подхватит её сама, флаг не нужен.

## Два правила приёмки

1. **Гость во всех пяти кадрах — один человек.** Тот же ракурс, свет и фон,
   меняется только выражение лица. Иначе на итоговом экране будет пять разных
   людей. Лист персонажа в `../ASSETS.md` переписывать в промт дословно.
2. **Никакого текста в кадре.** Вшитую надпись потом не поправить.
